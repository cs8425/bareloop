      new session

      An id is a directory name: lowercase letters, digits and . _ - only. One is suggested when this dialog opens - change it freely, or clear it and a new one is made up when you press create.

      The model, MCP servers, system prompt and compaction parameters are inherited from the server configuration; change them per session in settings.

      session settings

      An empty API key keeps the stored one. Each session keeps its own log, MCP servers, system prompt, context window and compaction parameters. Saving while a run is active is refused; MCP servers reconnect only when their list actually changed. Turning image attachments off sends the model one line about the image instead of its bytes, which is what a text-only server wants.

      Prices are per 1 000 000 tokens and carry no currency: they are yours. All three or none — a half-entered price would mis-bill every request quietly. Leave them empty on a session that has no prices yet and nothing is billed; put 0 in all three to say a session is free. Changing a price changes the totals of everything already in the log, because what is billed is the usage each request already recorded, and it never reconnects anything.
